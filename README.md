# System Administrator Career Portfolio

A responsive website made with plain HTML, CSS, and JavaScript. No React, build tools, database, or login are required.

## Files
- `index.html` — website structure and content
- `style.css` — design and responsive styling
- `script.js` — mobile navigation and interactive role comparison
- `images/` — local photos for the career pathway, skills, roles, tools, and About section
- `README.md` — setup, testing, and screenshot instructions

## Run the website
1. Extract the downloaded ZIP file.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Click navigation links to test all sections.
5. In Job Roles, click each role button and check that the description updates.
6. Resize the browser or use developer tools to check mobile responsiveness.

No `npm install` command is needed.
